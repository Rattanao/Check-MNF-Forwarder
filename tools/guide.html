Check all files — ไม่ต้องเลือกเมนูเอง

เมนูบนสุด Check all files รับ MANIFEST และ ENTER ของ Forwarder ไหนก็ได้ แล้วหาให้เองว่า ENTER แต่ละไฟล์เป็นฟอร์มของใคร จากนั้นตรวจด้วยกฎของเจ้านั้น

  1. ใส่ไฟล์ MANIFEST 1 ไฟล์ และ ENTER กี่ไฟล์ก็ได้ ENTER หลายเจ้าในเรือลำเดียวกันใส่พร้อมกันได้ · ใส่ SHED NO. ได้เหมือนเมนูปกติ
  2. กด “ตรวจสอบ” เวปลองอ่าน ENTER ด้วยตัวตรวจของทุกเจ้า (ใช้เวลาราว 5–20 วินาที) แล้วเลือกเจ้าที่รู้จักฟอร์มนั้น และอ่านเลข B/L ตรงกับ MANIFEST ได้มากที่สุด ถ้าหลายเจ้าใช้ฟอร์มเดียวกัน (เช่น INBOUND CARGO MANIFEST ของ CMS / Eastern Air / M-CORP / Penanshin) ดูจากชื่อเจ้าในเอกสารหรือชื่อไฟล์
  3. ดูตาราง “เป็นของ” ว่าแต่ละไฟล์ถูกจับคู่กับเจ้าไหน ถ้าไม่ถูก ให้ใช้เมนูของเจ้านั้นโดยตรง · ไฟล์ที่ขึ้น ไม่รู้จักฟอร์มนี้ ยังไม่มีเมนูที่อ่านได้
  4. ผลแยกเป็นแท็บละเจ้า แต่ละแท็บคือหน้าของเจ้านั้นเอง ค้นหา กรอง และดาวน์โหลด EDI <ชื่อเจ้า>.xlsx ได้ตามปกติ

ENTER ที่รวมหลายฟอร์มในไฟล์เดียว (เช่นชุดรวมของ HAHM) จะแยกเป็นหลายแท็บ แต่ละแท็บเห็นเฉพาะ B/L ที่ฟอร์มของเจ้านั้นอ่านได้ ที่เหลือขึ้นสีเหลือง — ไฟล์แบบนี้ต้องตรวจซ้ำด้วยคนเสมอ

ขั้นตอนการใช้งาน

  1. เลือก Forwarder จากเมนูด้านซ้าย ให้ตรงกับผู้ส่ง ENTER ค้นหาจากช่อง “ค้นหาเครื่องมือ” ได้ บนมือถือกดปุ่ม ☰ เพื่อเปิดเมนู
  2. ใส่ไฟล์ ลากไฟล์ MANIFEST และ ENTER มาวางพร้อมกัน หรือคลิกกรอบเพื่อเลือกไฟล์
    ตั้งชื่อไฟล์อะไรก็ได้ เวปแยกให้เอง (.xls/.xlsx = MANIFEST, .pdf = ENTER) · ENTER หลายไฟล์ของเรือลำเดียวกันใส่พร้อมกันได้ · Able, Handle Inter, LX Pantos, Planet, Sinotrans, Union World รับ MANIFEST แบบ PDF “CARGO MANIFEST” ได้ด้วย
  3. ใส่ SHED NO. (ถ้ามี) เช่น 0141 ทุก B/L ต้องตรงเลขนี้ ยกเว้นสินค้าไป LAOS · ถ้าไม่รู้เว้นว่างได้
  4. กดปุ่ม “ตรวจสอบ” ปุ่มจะกดได้เมื่อใส่ไฟล์ครบทั้ง MANIFEST และ ENTER
  5. ดูผลบนหน้าจอ ค้นหา B/L / ผู้รับ / เลขตู้ ได้ และติ๊ก “แสดงเฉพาะที่ไม่ตรง” เพื่อดูเฉพาะแถวที่ต้องแก้
  6. กด “ดาวน์โหลด EDI.xlsx” ไฟล์จะลงโฟลเดอร์ Downloads ชื่อตาม Forwarder เช่น EDI Union World.xlsx
  7. เริ่มงานใหม่ กดปุ่ม “ลบไฟล์” ข้างปุ่มตรวจสอบ เพื่อล้างไฟล์และผลเก่าทั้งหมด

หนึ่งแถวต่อหนึ่ง B/L ช่องซ้ายสุดสรุปว่าแถวนั้นต้องดูอะไร ค่าของ ENTER และ MANIFEST วางคู่กันทุกหัวข้อ แถวสุดท้าย TOTAL เทียบยอดรวมกับยอดที่เอกสารระบุเอง

ขาว — ไม่ผิด
เขียว — ผ่าน ไม่พบจุดผิด
แดง ⚠ — ไม่ตรงกัน ต้องแก้หรือยืนยันก่อนยื่น
ส้ม — ต้องให้คนยืนยัน เช่น ตัดบรรทัดต่างกัน หรือ B/L TRANSIT ที่ MANIFEST แบบ PDF ไม่มีข้อมูล
เหลือง — ไม่มีเอกสาร ENTER ให้เทียบ

หัวข้อที่เทียบทุก B/L

  • CONSIGNEE และ TAX ID
  • CONTAINER NO. และ STATUS
  • จำนวนและชนิดหีบห่อ (PKG), G.W., MEAS.
  • MARKS และ DESCRIPTION
  • SHED NO., ประเทศปลายทาง, CARGO MOVEMENT

เตือนเสมอเมื่อพบ

  • DG (CLASS / UN)
  • REEFER TEMP
  • INTRANSIT / TRANSHIPMENT
  • B/L ที่มีใน ENTER แต่ไม่มีใน MANIFEST (วิกฤต)
  • ยอดรวมแถว TOTAL ไม่ตรงกับที่เอกสารระบุ

กฎการเทียบที่ควรรู้

  • STATUS: CY / CY-CY / FCL / ลากตู้ = CY · LCL / ขน = LCL · CFS / LCL-CFS / เปิดตู้ = LCL/CFS
  • TRANSHIPMENT: CARGO MOVEMENT ต้องเป็น 3-TRANSHIPMENT
  • MARKS / DESCRIPTION เทียบแบบเข้ม ตัดเฉพาะช่องว่างและวรรคตอน
  • B/L ที่มีหลายตู้ ต้องตรงกับ MANIFEST ครบทุกตู้
  • ข้อความสีแดงที่ลูกค้าพิมพ์ทับ PDF ใช้กับ B/L ที่อยู่ใต้ข้อความ ถ้ามีคำว่า ทุก BL ใช้กับทุก B/L
  • SHED / ประเทศปลายทาง / CARGO MOVEMENT / TAX ID ถ้าถูกต้องตามกฎจะแสดง -

Check MNF Forwarder — User Guide

This site compares the shipping line's MANIFEST with each forwarder's ENTER document and produces a colour-coded Excel report, so every mismatch is visible before you file the import customs declaration.

MANIFEST (.xls/.xlsx)+ENTER (.pdf)→EDI <Forwarder>.xlsx

Files are processed only in your browser — nothing is uploaded anywhere. No installation needed.

Check all files — no need to pick a menu

The top menu, Check all files, takes a MANIFEST and ENTER files from any forwarder, works out whose form each ENTER file is, and checks it with that forwarder's rules.

  1. Add one MANIFEST and any number of ENTER files. ENTERs from several forwarders on the same vessel can go in together. SHED NO. works as in the normal menus.
  2. Click “ตรวจสอบ” (Check). The page reads each ENTER with every forwarder's checker (about 5–20 seconds) and picks the one that recognises the form and matches the most B/L numbers in the MANIFEST. When several forwarders share a form (e.g. the INBOUND CARGO MANIFEST of CMS / Eastern Air / M-CORP / Penanshin), the forwarder name in the document or file name decides.
  3. Check the “เป็นของ” (Belongs to) table to see which forwarder each file was matched to. If it is wrong, use that forwarder's own menu instead. A file marked ไม่รู้จักฟอร์มนี้ (unknown form) has no menu that can read it yet.
  4. Results come in one tab per forwarder. Each tab is that forwarder's own page, so search, filter and download EDI <Forwarder>.xlsx work as usual.

A single ENTER file that bundles several forwarders' forms (such as the HAHM bundle) is split across several tabs. Each tab shows only the B/Ls that forwarder's form reader could read; the rest show yellow. Always re-check such files by hand.

How to use

  1. Choose the forwarder in the left menu that matches whoever sent the ENTER. You can type in the search box. On a phone, tap ☰ to open the menu.
  2. Add the files. Drag the MANIFEST and ENTER in together, or click the box to pick them.
    File names don't matter — the page sorts them (.xls/.xlsx = MANIFEST, .pdf = ENTER). Several ENTER files for the same vessel can go in at once. Able, Handle Inter, LX Pantos, Planet, Sinotrans and Union World also accept a PDF “CARGO MANIFEST” as the MANIFEST.
  3. Enter the SHED NO. (optional), e.g. 0141. Every B/L must match it, except cargo for LAOS. Leave it blank if you don't know it.
  4. Click “ตรวจสอบ” (Check). The button becomes active once both a MANIFEST and an ENTER have been added.
  5. Review the result on screen. Search by B/L, consignee or container, and tick “แสดงเฉพาะที่ไม่ตรง” (show mismatches only) to see just the rows that need fixing.
  6. Click “ดาวน์โหลด EDI.xlsx” (Download). The file is saved to your Downloads folder, named after the forwarder, e.g. EDI Union World.xlsx.
  7. To start a new job, click “ลบไฟล์” (Clear files) next to the Check button. It removes all files and results.

Pick the menu that matches the ENTER form

Each menu reads only its own forwarder's ENTER form. If you use the wrong one, the page tells you the form is not supported.

Reading the report

One row per B/L. The leftmost column summarises what to look at in that row, and every field shows the ENTER value next to the MANIFEST value. The final TOTAL row checks the summed values against the totals each document states.

White — no error
Green — passed, nothing wrong found
Red ⚠ — mismatch; fix or confirm before filing
Orange — needs a person to confirm, e.g. different line breaks, or a TRANSIT B/L when a PDF MANIFEST lacks that data
Yellow — no ENTER document to compare against

Checked on every B/L

  • CONSIGNEE and TAX ID
  • CONTAINER NO. and STATUS
  • Package count and type (PKG), G.W., MEAS.
  • MARKS and DESCRIPTION
  • SHED NO., destination country, CARGO MOVEMENT

Always flagged when found

  • DG (CLASS / UN)
  • REEFER TEMP
  • INTRANSIT / TRANSHIPMENT
  • A B/L in ENTER that is missing from MANIFEST (critical)
  • TOTAL row not matching the totals the documents state

Comparison rules worth knowing

  • STATUS: CY / CY-CY / FCL / container haul = CY · LCL / unload = LCL · CFS / LCL-CFS / devanning = LCL/CFS
  • TRANSHIPMENT: CARGO MOVEMENT must be 3-TRANSHIPMENT
  • MARKS / DESCRIPTION are compared strictly — only spaces and punctuation are ignored
  • A B/L with several containers must match the MANIFEST on every container
  • Red text the customer typed over the PDF applies to the B/Ls below it; if it says ทุก BL (all B/Ls) it applies to every B/L
  • SHED / destination country / CARGO MOVEMENT / TAX ID show - when they follow the rules
